# Kioku extra files for add-ons

Downloaded by the Kioku apps when an add-on needs them (Tools › Add-ons › Extra Files).
Built by `shared/tools/packs.py` on the main branch; listed in `shared/python/kioku/packs.json`. Old versions stay for older apps.

| espeak-data-*.zip | [eSpeak NG](https://github.com/espeak-ng/espeak-ng)'s data, compiled by `shared/tools/build_programs.sh` | GPL-3.0-or-later |
