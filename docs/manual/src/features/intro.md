# Kioku-only Features

Things Anki on a computer doesn't do. All but links and gamepads are off until you turn them on:

| Feature | Variants | Where |
| --- | --- | --- |
| [Sync server on the phone](sync-server.md): AnkiDroid, Kioku's profiles and Anki on your computers sync with the phone instead of AnkiWeb | iPhone, Android native, Android Termux | Preferences › Advanced |
| [AnkiDroid's media](ankidroid.md): a profile uses AnkiDroid's media folder, so big media is stored once; syncs when you switch apps (native only) | Android native, Android Termux | Preferences › Advanced |
| [Remote desktop](remote-desktop.md): use the phone's Anki from a computer's web browser or VNC viewer | Android Termux | Settings › Remote desktop |
| [kioku:// links](links.md): other apps and Shortcuts add notes, sync and search, like AnkiMobile's `anki://` links | iPhone, Android native | always on |
| [Gamepads and controllers](gamepad.md): study and move around with a Bluetooth or USB game controller; each button's action can be changed | iPhone, Android native | Preferences › Advanced (on) |
