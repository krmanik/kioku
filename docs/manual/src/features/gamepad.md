# Gamepads and Game Controllers

> **Applies to:** iPhone and iPad, Android native

Study and move around Kioku with a Bluetooth or USB game controller: Xbox,
PlayStation, Nintendo Switch Pro, 8BitDo and other controllers that the
phone itself supports. Pair it in the system's Bluetooth settings (or plug
it in); Kioku says "… connected" and the buttons work at once.

Buttons are named by position, as on an Xbox controller: **A** is the
bottom face button (PlayStation cross, Switch B), **B** the right one, **X**
the left one, **Y** the top one.

## Default buttons

| Button | While studying | Everywhere else |
| --- | --- | --- |
| A | Question: Show answer. Answer: Good | Select: open the highlighted deck, study it, press a dialog's button |
| B | Answer: Again | Back: deck overview → deck list; close a dialog or menu |
| X | Answer: Hard | — |
| Y | Answer: Easy | Sync |
| D-pad, left stick | Up and down scroll the card | Move: the highlight on the deck list (left and right collapse and expand a deck), the focus in a dialog, the item in a menu |
| Right stick | Scroll | Scroll |
| Left / right bumper | Undo / Replay audio | Previous / next item (like Shift+Tab, Tab) |
| Menu (Start, Options, +) | The review's More menu | — |
| View (Back, Select, Share, −) | Back to the deck overview | Back |

The d-pad and the left stick repeat while held. Again, Hard, Good and Easy
use the answer keys set in Anki's Preferences, so they follow your
keyboard settings.

## Change the controls

**Preferences › Advanced › Gamepad › Controls…** works like AnkiDroid's
Settings › Controls: a list of actions for **Studying** and one for
**Elsewhere**, each with its buttons.

- Tap an action, then **Add Button…**, and press the button on the
  controller. While studying, choose whether it works on the
  **Question**, the **Answer** or **Both** sides, so one button can do
  different things on each side. If another action has that button, Kioku
  says which; OK moves it.
- Tap a button in the list to remove it. An action can have several
  buttons.
- **Add Keyboard Shortcut…** makes an action from any keyboard shortcut,
  typed as Anki's menus show it (`Ctrl+Shift+D`, `*`), so add-ons'
  shortcuts work too.
- **Restore Defaults** puts every button back.

The settings apply to every profile and are Kioku's own: they are not in
your collection and don't sync. Turn the Gamepad checkbox off to give the
controller back to the system and to web pages.

## Limits

- Pages with their own controls (the editor, deck options, statistics)
  take the controller only for Back; use touch for the rest.
- iPhone and iPad: a message box with buttons is the system's own alert
  and takes touch only. A drop-down list opens the system's picker.
- Add-ons that read the controller themselves, such as Contanki: turn
  Kioku's gamepad off (Preferences › Advanced) to use them, so that a press
  doesn't run both.
