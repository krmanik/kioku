• Manual: step-by-step guide for syncing a computer or tablet with the phone's sync server over Wi-Fi, the phone's hotspot or Tailscale, based on a tutorial shared in issue #25. See Sync server on the phone.
• iOS, Android, Termux app: no "Preferences Corrupt" message after Kioku was closed during its first start, for example on the language question. Anki saves its settings only later, so the next start found an empty settings file. Kioku now starts as on a first run instead.
• iOS, Android, web: Kioku runs on the Python and Qt versions desktop Anki uses (Python 3.13, Qt 6.11). Before, it used Python 3.14, and some add-ons failed to load there, such as AnkiHub.
• Android: after answering a card, the next card has the keyboard focus again, so a {{type:}} box and add-ons that listen for keys get the typing (issue #24).
• Android: with a hardware keyboard, Anki's shortcuts (Space, Enter, 1–4 in the reviewer, and the others) work after you tap a page. Before, the page kept every key. Keys still reach text fields and cards that listen for them.
• Phones and tablets: the buttons under the deck list (Get Shared, Create Deck, Import File) and under a deck's overview are bigger and easier to tap.
• iPhone, iPad: View › Zoom In and Zoom Out make pages bigger and smaller again, as do add-ons that zoom. Before, the text stayed the same size and the page only moved to the right. Preferences › User interface size now also zooms the pages.
• Android: View › Zoom In and Zoom Out, add-ons that zoom and Preferences › User interface size zoom the whole page. Before, only the text got bigger.
• Android: the editor's MathJax buttons (Equations menu) work with recent versions of Android System WebView. The equation stayed plain text.
• Termux app: Anki starts again inside the desktop. 0.2.9 left out a file Preferences › Advanced needs, so the desktop came up without Anki (issue #13). The Termux app no longer shows the Gamepad settings: its desktop gets no controller input.
• Termux app: Anki runs on the Python and PyQt versions desktop Anki uses (Python 3.13, PyQt 6.11), like the iPhone, iPad and Android apps. Before, it used Termux's Python 3.14, and add-ons that don't work there failed to load, such as AnkiBrain (issue #23).
• iOS: add-ons that other apps connect to, such as AnkiConnect, can keep answering after you leave Kioku. Turn on Preferences › Advanced › Background › Keep running in the background (off by default). iOS pauses apps a few seconds after they leave the screen, so dictionary and reader apps couldn't reach AnkiConnect and kept spinning. The option uses location updates to keep Kioku running, at the lowest accuracy and approximate by default. Kioku ignores the location: nothing is saved or sent. Only Kioku's own location request works: add-ons and web pages that ask for location get nothing (Add-ons that other apps connect to, issue #21).
• iOS, Android: pictures and sounds keep downloading after a sync with AnkiWeb when the connection drops. On iPhone, leaving Kioku or locking the screen during the download stopped it with "Connection timed out" (or an HttpError message): the cards were there, but most pictures, image occlusion ones included, were missing until the next manual sync. Kioku now tries again by itself, and again when you come back to it, until the download completes. While it runs, the Sync button shows how many files came down.
• iOS: a sync keeps running for a short while after you leave Kioku, and the screen doesn't lock while one runs.
• iOS, Android: show and hide the browser's columns with touch, in View › Columns. Anki offers them in the column headers' context menu, which needs a right-click (issue #20).
• iPhone: number fields, such as Custom Study's "Increase today's new card limit by", get a Done button above the number pad. The pad has no Return key, so the keyboard couldn't be closed and covered the OK button.
